FreeLaunch Hub landing page — real photo version

Files:
- index.html: landing page structure and links
- style.css: responsive styles, teal theme, and real photo backgrounds
- script.js: mobile menu, category search/filter, current footer year

Run:
1. Keep all 3 files in the same folder.
2. Put your existing login page in this folder as login.html, OR update href="login.html" links in index.html to your existing login path.
3. Open index.html in a browser or deploy the folder to hosting.

Photos:
This version uses remotely hosted Unsplash photo URLs, so internet access is required for images to load. If a URL is unavailable, replace it with another image URL or download licensed images and update the CSS/HTML paths.

Login:
The Login / Join Us buttons route to login.html. Keep your existing PHP/backend authentication code to retain actual login and database functionality. The About Us black section remains empty for your own content.
