❓ FAQ & Helpdesk

Quick answers for common tasks
How do I create a new product?

Choose “Create new product”, fill in the title, category, tools, description, sample image and three packages, then review and publish.

How do I accept and deliver an order?

Open Order Box, review customer requirements, add a note or suggestion, and select Accept Order. When work is ready, add delivery details and select Deliver Order.

Why are views, clicks or earnings zero?

Metrics are based on activity tracked in this browser demo. Earnings show order values only; this project does not process payments.

Need more help?

Use the order box to review customer details, and check your profile and product listing fields. For a production launch, connect a shared database and support system.
